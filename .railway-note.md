# Railway Deployment Note

## Rust Files Disabled for Node.js Deployment

The following files have been temporarily renamed to prevent Railway from detecting this as a Rust project:

- `Cargo.toml` → `Cargo.toml.rust-disabled`
- `Cargo.lock` → `Cargo.lock.rust-disabled`

**Why**: Railway's Railpack builder has higher priority than Dockerfile. Even with `railway.json` configured for Docker, Railway auto-detects `Cargo.toml` and builds Rust instead of Node.js.

**To re-enable Rust locally**:
```bash
mv Cargo.toml.rust-disabled Cargo.toml
mv Cargo.lock.rust-disabled Cargo.lock
```

**Alternative long-term solution**: Use Railway's monorepo support to deploy from a subdirectory, or maintain separate repositories for Rust and Node.js components.
