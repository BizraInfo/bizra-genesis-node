## Quick Start

### Sovereign Activation
```powershell
cd C:\bizra-genesis-node
.\GENESIS_ZERO_SOVEREIGN.ps1
```

This script:
1. ✅ Verifies your BIZRA Model Stack is running
2. ✅ Starts PostgreSQL + Redis
3. ✅ Applies database migrations
4. ✅ Starts Rust backend with sovereign model config
5. ✅ Starts React dashboard
6. ✅ Generates SAT-LAB content using YOUR model
7. ✅ Opens your PAT Dashboard

### Skip Options (for faster restarts)
```powershell
# Skip everything already running
.\GENESIS_ZERO_SOVEREIGN.ps1 -SkipDocker -SkipMigrations -SkipModelCheck

# Use a specific model
.\GENESIS_ZERO_SOVEREIGN.ps1 -PrimaryModel "llama3.2"
```

## Troubleshooting

### "Ollama not running"
```powershell

```

### "Model not found"
```powershell
# List available models
ollama list

# Pull a model if needed
ollama pull llama3.2
```

### "Database connection failed"
```powershell
docker-compose -f docker-compose.database.yml up -d
docker-compose -f docker-compose.database.yml logs postgres
```
