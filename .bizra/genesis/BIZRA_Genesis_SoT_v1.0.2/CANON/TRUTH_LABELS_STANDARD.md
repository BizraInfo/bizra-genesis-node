# Truth Labels Standard v1.0

Every statement in BIZRA canon is labeled:

- IMPLEMENTED: exists in code and is reproducible
- MEASURED: backed by receipts (hashes + replay bundle)
- DERIVED: extracted from validated canon artifacts (e.g., this Atlas PDF)
- TARGET: numeric target, not yet achieved
- PLANNED: intended design, not implemented
- ASSUMPTION: placeholder requiring validation

Rule: No unlabeled claims in canon, code docs, or receipts.
